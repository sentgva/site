# Amazona — лендинг питомника экзотических попугаев

Статичный сайт без сборки и зависимостей: откройте `index.html` в браузере.

## Что внутри

- **Полёт через вольер.** Первый экран закреплён, а скролл двигает камеру вглубь 3D-сцены мимо листьев и карточек с птицами.
- **Живые попугаи.** Птицы нарисованы в SVG и следят глазами за курсором. При наведении поворачивают голову, машут крылом и здороваются, а у какаду поднимается хохол.
- **Эффекты мыши.** Свой курсор, 3D-наклон и блик на карточках, перья из-под курсора, по клику вылетает целый ворох перьев.
- **Каталог** с фильтром по размеру, **шаги покупки** с птичкой, которая летит по линии прогресса, блок **вопросов** и **форма заявки**.
- Светлая и тёмная темы, адаптив под телефон, учёт настройки «уменьшить движение».

## Структура

```
index.html            разметка и тексты
assets/css/style.css  стили и палитра (токены в :root)
assets/js/parrots.js  данные о птицах и генератор SVG-иллюстраций
assets/js/main.js     интерактив: сцена, курсор, карточки, форма
```

## Как поменять

- **Птицы, цены, наличие:** массив `PARROTS` в `assets/js/parrots.js`. Цвета оперения задаются в поле `c`.
- **Отправка заявки:** форма пока никуда не отправляет данные. Точка подключения отмечена комментарием в `assets/js/main.js` (обработчик `submit`).
- **Контакты и тексты:** `index.html`.
